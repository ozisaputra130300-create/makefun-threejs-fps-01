Duskline Depot: a round-based tactical FPS in a rail depot at dusk. One striker against five depot guards — plant the charge at the Crane Yard or the Warehouse, or drop every guard. First to 6 rounds takes the depot. Built on three.js 0.187.0, no build step, no network: static files under `game/`, bots with hold/patrol/rotate/investigate/hunt/engage/defuse AI (one dedicated hunter tracks your last known position), an economy with a buy menu (six guns, frag + smoke grenades, body armour), and gunplay where stopping to aim pays. A second, enclosed area — the drainage tunnel — gives a quiet flank route from mid to the Warehouse.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
